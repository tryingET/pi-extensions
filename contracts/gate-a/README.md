# Gate A public contract fixtures

This additive candidate package covers pi-agent-registry release evidence, pi-vault-client materialization, capability descriptors and extension-hook inventory, ASC effect receipts, the cross-owner runtime fixture, and the shared claim/failure/effect crosswalk. It changes no current dispatch path and activates no agent.

The generic provider-qualified resource shape is owned by `tryingET/core_tpl-template-repo`; schemas here use its `$id` by reference. All files under `fixtures/` are synthetic compatibility vectors unless a file explicitly says source inventory. A fixture hash is not approval, appointment, authorization, runtime proof, or effect settlement.

Rollback is feature-flag disable plus preservation of the current schema-1/Phase-2 path. Implementation and live dispatch remain Stage B.
