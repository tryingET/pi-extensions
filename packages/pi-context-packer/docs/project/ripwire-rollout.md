# Ripwire rollout status

**Explicit use is implemented. Automatic activation is OFF.**

The committed `RIPWIRE_AUTO_APPROVAL` record is immutable and disabled. A model
parameter or environment opt-in cannot substitute for reviewed adoption evidence.
`providers.ripwire: required` requests code; `off` prevents execution.
`PI_CONTEXT_PACKER_RIPWIRE_DISABLED=1` is an operator kill switch that also blocks
explicit requests before binary reading, source copying, cache access or subprocesses.
There is no replacement backend or automatic installation.

The policy supports relevance, available-headroom, provisioning and a trusted host
assertion that a request is already satisfied. A nonempty working set by itself does
not establish that the current objective has been answered. Automatic selection,
when approved in a later reviewed promotion, is selection within `context_pack`,
not an unconditional every-turn injection hook. Automatic-provider failures remain
omissions; explicit required failures make the packet incomplete.

repository state, permissions and budgets, including fallbacks and repeated packets.
