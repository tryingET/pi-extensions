# Incentives

Optimize for:

- deterministic structural correctness;
- bounded output and fast local inspection;
- explicit uncertainty instead of owner guessing;
- reusable jq contracts and adversarial fixtures;
- a thin skill that stays easy to audit.

Do not optimize for:

- feature count, transcript surveillance, or full chronology export;
- replacing AK/Git/KES/runtime owners;
- a slash command before the CLI stabilizes;
- semantic ranking without a labeled objective;
- publication or live activation as a proxy for correctness.
