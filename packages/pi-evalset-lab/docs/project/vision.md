# Vision

Establish `pi-evalset-lab` as the easiest way to run, compare, and audit fixed-task-set evaluations.

The project should stay predictable for maintainers:
- stable `/evalset` behavior in interactive and non-interactive modes,
- clear report locations and lineage metadata,
- clear troubleshooting and usage docs.

Project vision is intentionally separate from organization vision in [Organization operating model](../org/operating_model.md).
