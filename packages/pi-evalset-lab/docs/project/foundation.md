# Project foundation model

## Project purpose
Build and maintain `pi-evalset-lab` as a practical extension package for fixed-task-set evaluations in pi.

## Project mission (current cycle)
Consolidate reliability by tightening command behavior, report lineage metadata, and release confidence checks.

## Scope boundary
- Organization purpose lives in [Organization operating model](../org/operating_model.md).
- This project purpose is repository-specific and intentionally narrower.

## Project operating principles
- No regressions in existing `/evalset` commands.
- Prioritize reproducibility and UX clarity over feature breadth.
- Keep command behavior and report lineage metadata explicit.
- Validate structure after meaningful changes.
