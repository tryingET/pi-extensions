## Strong schools and the actual decision

- **Formal concurrency:** exact owner, epoch, token and revision comparisons dominate
  presentation or sampling convenience. A stale grant must never regain authority.
- **Incremental test-driven change:** a narrowly discriminating executable scenario
  dominates a broad rewrite. An instrument needs negative controls of its own.
- **Human-interface agency:** a green suite is irrelevant if subsequent typing goes
  to the wrong application. Real input and delayed return checks are indispensable.
- **Recovery-first operations:** a source patch is not durable deployment. The exact
  controller/runtime/native pair needs startup and compatible rollback proof.

The real clash is convenience versus evidence: faster exact-position return cannot
be asserted safe merely because a client callback resembles motion; a broad
cross-language coordinator cannot be justified merely because some rules repeat.
**Contextual dominance** is the decision: fail-closed identity/agency controls win
ambiguous cases, incremental characterization precedes restructuring, and recovery
proof precedes live promotion. Preserve separately defended expectations rather
than averaging them into weaker assertions.

The existing private protocol remains2. An additive `keyboard-observation` event
contains only request, origin, reason, native monotonic timestamp, optional native
idle deadline and actual captured state. No query, prompt, credential, path or
window title enters this record. The native producer observes existing acquisition,
key-activity renewal, idle-expiry and source-revocation branches; it changes no
permission, timer, keyboard mode or transition policy.

Native Rust and controller JavaScript use the shared protocol cases to check their

native observation**, not current input authority or a countdown. It never
subtracts a controller wall clock from a native timestamp. Explicit mode reports
no hover idle deadline. An older protocol2 panel simply leaves this optional
observation unknown; protocol1 still fails admission. Unknown fields are dropped.
