# Vision

Make trusted local data gathering easier to express and easier to correct through
compiler feedback, without advertising nonexistent security isolation.

The present scope is one stateless TypeScript tool with two filesystem helpers.
Additional capabilities, persistence and stronger execution isolation are not
implicit roadmap commitments; they require separately authorized work.
