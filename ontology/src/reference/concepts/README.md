# Repo Concepts

Add repo-local concepts here only when needed.

Guideline:
- keep concepts here when they are specific to `pi-extensions` root or a not-yet-generalized cross-package capability
- propose promotion to `softwareco/ontology` only when the concept is clearly useful across many repos
- propose promotion to core only when the concept is clearly stable across companies
